# Задача 2 — расчётное ядро мини-разбора

**Дата:** 2026-05-20 · Статус: ✅ утверждено владельцем 2026-05-20 — вариант «Стандарт» (солнце + луна + главное число + число дня + синтез, ~117 блоков RU).

## Что реально посчитать на устройстве без внешних сервисов

| Позиция | Требует | Точность на устройстве | Вердикт для v1 |
|---|---|---|---|
| Солнечный знак | дату | абсолютная (кроме ~суток на границах знаков — честно помечаем) | ✅ в ядро |
| Главное число сюцай | дату | абсолютная (арифметика по цифрам даты) | ✅ в ядро, формулу подтверждает Катя |
| Число дня рождения | дату | абсолютная | ✅ кандидат |
| Лунный знак | дату + желательно время | компактный астрономический расчёт даёт знак верно в ~97% случаев; без времени считаем на полдень и честно помечаем возможную границу | ✅ кандидат (сильно поднимает «личность» результата — луна у всех разная при одном солнце) |
| Асцендент | точное время + координаты места | без справочника геокоординат непосчитаем — место у нас свободным текстом | ❌ не в v1; ценность асцендента — аргумент персонального уровня |
| Психоматрица сюцай (полная) | дату | считается, но требует большой текстовой базы | ❌ не в v1; глубина — аргумент платных уровней |

## Модульная сборка (утверждённая гипотеза плана)

Результат собирается из независимых блоков — каждый блок описывает одну позицию, база растёт линейно, а не мультипликативно. Синтез двух систем (принцип 7 канона) обеспечивается специальным синтез-блоком по укрупнённым группам: четыре стихии знака × три группы чисел = 12 сочетаний, без взрыва комбинаторики.

Структура выдачи: блок солнца по фокусу → блок луны → блок главного числа по фокусу → синтез-блок → границы разбора (что учтено, что нет).

## Три варианта объёма базы (русский язык; EN/LT — перевод)

| Вариант | Состав | Блоков RU | Оценка объёма |
|---|---|---|---|
| **Минимум** | солнце×4 фокуса (48) + главное число×4 фокуса (36) + синтез (12) | ~96 | ~7–8 тыс. слов |
| **Стандарт (рекомендую)** | минимум + луна (12, общие для фокусов) + число дня (9) | ~117 | ~9–10 тыс. слов |
| **Богатый** | стандарт + луна по фокусам (48 вместо 12) + синтез по фокусам (48 вместо 12) | ~200 | ~16–18 тыс. слов |

Рекомендация: **стандарт**. Луна — самый дешёвый способ сделать результат ощутимо личным (два человека с одним солнцем почти всегда различаются луной), а фокусная дифференциация луны и синтеза даёт мало прироста за double работу.

## Что требует подтверждения Кати (передаётся в задачу 3)

1. Формулы чисел сюцай: какое число считается главным, как редуцируется, считается ли число дня — по её методике, не по общей нумерологии.
2. Группировка чисел для синтез-блока (какие числа она считает родственными).
3. Согласие с честными пометками о границах точности (граница знаков, луна без времени).
